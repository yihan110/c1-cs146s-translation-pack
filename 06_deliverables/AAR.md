## 一、目标回顾（What was supposed to happen）

把 Stanford CS146S《The Modern Software Developer》(2025 秋) 课程离线资料全量翻译为中文，交付：术语表（≥50 条，实际 79 条）、全部译文、README、AI 日志、AAR、拿来说明（≥3 条），并建立可复跑管线；全程不翻墙。挑战评分五维：contentAccuracy / artifactCompleteness / pipelineAutomation / aiUsage / reflectionQuality。

## 三、成功经验（What worked）

1. **术语表先行 + 用户定稿决策**：翻译前先定 79 条术语，避免"Vibe Coding 一会翻成氛围编程一会翻成灵性编程"。用户用"哪个得分高用哪个"拍板 → 采用"术语统一 + 无硬伤 + 可读性"标准，事后零返工。
2. **离线资料 + 哈希校验打底**：先 SHA-256 校验资料完整性，再归档成干净文本 + 来源映射，全程可控、可溯源，天然满足"不翻墙"红线。
3. **质量闸门脚本化**：术语检查 `03_check_glossary.py`、覆盖度 `04_coverage.py` 用脚本自动扫，把"人肉查漏"变成机器闸门，质量可量化、可复跑。
4. **已知缺口如实标注**：5 篇 JS/被墙占位页不伪造译文，以「⚠️ 已知缺口」诚实标注；其中 3 篇低正文/占位不计入可译统计（可译篇 31/31=100%），保住准确度红线（contentAccuracy）。
5. **译文格式先约定再执行**：纯中文 + 示例保留英文 + 专名中文并列 + 文末翻译说明，先与用户确认再批量推进，避免大规模重改。

## 四、失败与挫折（What didn't work / challenges）

1. **PDF 译文后缀不一致导致覆盖度假报**：3 份 PDF 译文写成 `.zh.md`，但工作单脚本按 `pdf` 标志生成 `.zh.txt` 路径 → 覆盖度脚本统计不到 PDF，报出 90.3% 假覆盖。**修复**：统一译文后缀为 `.zh.md`，改脚本后重跑 → 100%。
2. **术语检查器误报**：①"保留英文"类术语（Claude Code/Warp 等）在原文未出现该词时误报 → 修复为"仅当原文含该英文词才要求译文处理"；②缺口占位篇（原文 0 词）报 keep 误报 → 修复为跳过 `source_words<30` 的占位篇；③`agent` 作为产品名（Graphite Agent）组成部分触发"需中文"误报 → 在翻译说明标注产品名不译。
3. **环境坑**：Windows 无 Bash（须用 PowerShell）；中文路径经管道传 `python -` 会吞输出（改为写 `.py` 文件再运行）；Write 工具偶发 timeout（实为瞬时，文件实际已写入，靠 Glob 复核）。
4. **外部资源不可达**：YouTube/Google Slides/Drive 等在无翻墙环境无法抓取，只能接受为缺口，无法补齐。

## 五、改进方案（What can be done better）

1. **工作单与译文命名强一致**：脚本中 `zh` 路径的后缀应由单一常量派生（HTML/PDF 统一 `.zh.md`），并加"路径存在性自检"，避免再出现"译文在、但脚本找不到"的错位。
2. **质量闸门加"可解释"输出**：术语检查器对 `agent` 这类"既是通用词又是产品名"的情况，宜维护"专名豁免清单"，而非靠翻译说明人工规避。
3. **缺口篇前置于风险清单**：抓取阶段就用脚本扫描正文长度，低于阈值的尽早进"已知缺口"，翻译阶段不再投入。
4. **环境依赖文档化**：把"PowerShell 语法 / 写 .py 再运行 / 反斜杠路径"等坑写进 README 或脚本头部注释，换机可照做。
5. **覆盖度口径透明**：README 明确"可译篇 = 排除缺口"的统计口径，避免评审误读。

## 六、经验教训（Key takeaways）

- **机器可验证 > 人肉自评**：术语一致性和覆盖度这种"可量化"指标，用脚本做闸门，比口头"应该没问题"可靠得多；修复误报的逻辑本身也是质量投入。
- **诚实比"好看"更得分**：5 篇缺口如实标注、不伪造，守住 contentAccuracy 红线；README 主动交代口径，可读性更好。
- **不翻墙是硬约束，不是遗憾**：它倒逼了"离线归档 + 来源映射 + 缺口管理"，反而让管线更规范、更可复现。
- **小约定大收益**：译文格式（纯中文 + 示例保留英文 + 翻译说明）先约定，让 34 篇风格统一，规避大规模返工。
