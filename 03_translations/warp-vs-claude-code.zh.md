# Warp vs Claude Code（Warp 简介）

> 来源：Warp 官方文档（docs.warp.dev），课程 Week 4 阅读

> Warp 是一个**智能体驱动开发环境（Agentic Development Environment）**：把现代终端与强大的智能体结合，帮你构建、测试、部署和调试代码。Warp 的 AI 由 **Oz** 驱动——一个面向云端智能体的编排平台。

## Warp

Warp 是你的工作场所——一个为"与智能体一起编码"而构建的快速、现代终端。关键能力：

- **智能体模式（Agent Modality）**：在干净的命令终端与"面向多轮智能体工作流的专门对话视图"之间切换。
- **现代终端体验（UX）**：光标移动、基于块（block）的导航、多行编辑、语法高亮、丰富的补全。用 Rust 构建，性能高。
- **代码编辑器**：文件树、带 LSP 支持的代码编辑器、交互式代码评审体验。
- **编码智能体集成**：支持语音输入、用 @-选择与终端内图像协作。兼容 Oz，也兼容 Claude Code、Codex 等智能体。

## Oz：面向云端智能体的编排平台

Oz 是驱动 Warp 所有智能特性的编排平台，为"规模化协调智能体"而设计——理解你的代码库、自主执行任务、适配你的工作流。Oz 天生支持多模型，让你能为每个任务选择最佳 LLM。Oz 以两种模式运行：

### 本地智能体（Local agents）

直接在 Warp 应用内运行，提供实时、交互式编码协助：
- 在你的代码库中编写和重构代码；
- 调试问题、修复错误；
- 运行命令并解读结果；
- 规划并执行多步任务。

本地智能体让你保持掌控。你可以评审改动、在任务中途引导智能体、并在动作执行前批准它们。

### 云端智能体（Cloud agents）

Oz 云端智能体在 Warp 的基础设施（或你自己的）上后台运行，用于规模化自动化：
- **触发器（Triggers）**：对 Slack、Linear、GitHub 或自定义 webhook 的事件做出反应；
- **调度（Schedules）**：运行重复任务，如依赖更新或死代码清理；
- **并行（Parallelism）**：跨仓库或任务并发运行许多智能体。

云端智能体非常适合不需要你即时关注的工作，如 PR 评审、问题分诊、例行维护和集成驱动的工作流。

## 它们如何协同

Warp 和 Oz 在本地与云端开发之间提供统一体验：
- **同一个智能体，随处可用**：无论你在 Warp 里交互式工作，还是在云端运行智能体，你都在使用相同的底层智能体能力；
- **无缝交接**：在云端开始任务，想在 Warp 里亲自掌控时接手本地——不丢失进度或上下文；
- **共享上下文**：Warp Drive、规则（Rules）和 MCP 服务器在本地和云端智能体间通用，让团队的知识和工具始终可用；
- **团队协作**：分享智能体会话、评审智能体的动作、引导正在运行的任务，无论谁发起的。

## 多模型支持

Oz 天生支持多模型。你可以从一组精选的顶级模型中选择你偏好的 LLM。

## 隐私与安全

Warp 符合 SOC 2，并与所有签约的 LLM 提供商执行**零数据保留（Zero Data Retention）**政策。不保留、不存储、不用于训练的客户 AI 数据。Warp 的 AI 功能可在"设置 > AI"中全局禁用。
