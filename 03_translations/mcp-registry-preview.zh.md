# MCP 注册表预览（MCP Registry Preview）

> 来源：MCP 官方博客（2025-09-08），课程 Week 2 阅读

今天，我们推出**模型上下文协议（MCP）注册表**——一个面向公开 MCP 服务器的开放目录与 API，旨在改善可发现性与实现。通过标准化服务器的分发与发现方式，我们在扩大其触达范围的同时，也让客户端更容易完成连接。

MCP 注册表现在已开放预览。要开始使用：
- 添加你的服务器：遵循《向 MCP 注册表添加服务器》指南（面向服务器维护者）
- 访问服务器数据：遵循《访问 MCP 注册表数据》指南（面向客户端维护者）

## MCP 服务器的单一事实来源

2025 年 3 月，我们分享过想为 MCP 生态系统构建一个中央注册表的想法。今天宣布：`https://registry.modelcontextprotocol.io` 已作为官方 MCP 注册表上线。作为 MCP 项目的一部分，MCP 注册表及其父级 OpenAPI 规范都是**开源的**——让所有人都能构建兼容的子注册表。

我们的目标是标准化服务器的分发与发现方式，提供一个可供子注册表建立在之上的主要事实来源。反过来，这将扩大服务器触达范围，帮助客户端在 MCP 生态系统中更容易找到服务器。

## 公共与私有子注册表

在构建中央注册表时，对我们重要的是不削弱社区和公司已建立的现有注册表。MCP 注册表作为公开可用 MCP 服务器的主要事实来源，组织可以基于自定义标准创建子注册表。例如：

- **公共子注册表**：像与各 MCP 客户端相关联的、有主见的"MCP 市场"，可以自由增补和增强它们从上游 MCP 注册表摄取的数据。每种 MCP 终端用户画像都有不同需求，由 MCP 客户端市场以有主见的方式妥善服务其终端用户。
- **私有子注册表**：将存在于有严格隐私与安全要求的企业内部，但 MCP 注册表给了这些企业一个可建立在之上的单一上游数据源。至少，我们旨在与这些私有实现共享 API schema，使相关 SDK 和工具能跨生态共享。

在这两种情况下，MCP 注册表都是起点——它是服务器维护者发布和维护其自报信息的中枢位置，供下游消费者整理并交付给终端用户。

## 社区驱动的审核机制

MCP 注册表是一个由注册表工作组维护、采用宽松许可的官方 MCP 项目。社区成员可以提交 issue，标记违反 MCP 审核指南的服务器——例如包含垃圾信息、恶意代码，或冒充合法服务的服务器。注册表维护者随后可将这些条目加入拒绝列表（denylist），并从公共访问中追溯移除。

## 开始使用

要开始：添加你的服务器（《向 MCP 注册表添加服务器》指南）或访问服务器数据（《访问 MCP 注册表数据》指南）。这个 MCP 注册表预览旨在帮助我们在正式发布前改进用户体验，不提供数据持久性保证或其他担保。我们建议 MCP 采用者密切关注开发进展，因为在注册表正式发布前可能出现破坏性变更。

随着我们继续开发注册表，我们欢迎在 modelcontextprotocol/registry GitHub 仓库上提出反馈与贡献：Discussion、Issues 和 Pull Requests 都欢迎。

MCP 注册表从一开始就是协作的成果，我们非常感谢更广大开发者社区的热情与支持。2025 年 2 月，它作为一个草根项目起步——当时 MCP 创作者 David Soria Parra 和 Justin Spahr-Summers 请 PulseMCP 和 Goose 团队帮助构建一个集中式社区注册表。来自 PulseMCP 的注册表维护者 Tadas Antanavicius 与来自 Block 的 Alex Hancock 合作，牵头了最初的工作。他们很快迎来了注册表维护者、GitHub 的 MCP 负责人 Toby Padilla；近期，来自 Anthropic 的 Adam Jones 作为注册表维护者加入，推动项目走向今天的发布。MCP 注册表开发的最初公告列出了来自至少 9 家公司的 16 位贡献者。许多其他人也做了关键贡献：Stacklok 的 Radoslav Dimitrov、GitHub 的 Avinash Sridhar、VS Code 的 Connor Peet、NuGet 的 Joel Verhagen、Last9 的 Preeti Dewani、Microsoft 的 Avish Porwal、Jonathan Hefner，以及许多提供代码评审与开发支持的 Anthropic 和 GitHub 员工。我们也感谢注册表贡献者日志上的所有人、以及参与讨论和 issue 的人。

我们深深感谢每一位投入这项基础开源基础设施的人。一起，我们正帮助全球的开发者与组织构建更可靠、有上下文感知的 AI 应用。谨代表 MCP 社区，感谢你们。
